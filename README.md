# House walk

Walk through the house in the browser: WASD + mouse on a computer, thumb controls on a phone.
three.js with capsule collision against the model (three-mesh-bvh).

- `index.html` – the page
- `house.glb`, `doors.json` – exported from Blender by `export_glb.py` (run it after rebuilding the model)
- `walk.bat` – serves the folder locally on http://localhost:8765/
